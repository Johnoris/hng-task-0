# Simple Personal Info API

A basic API that returns personal information - email, current datetime, and Project GitHub URL.

## Setup
1. Install dependencies:
```bash
npm install
```

2. Run the server:
```bash
npm start
```

## API Documentation

### Get Personal Info
- **URL**: `/`
- **Method**: `GET`
- **Response**:
```json
{
    "email": "johnorisanwo@gmail.com",
    "current_datetime": "2025-01-28T12:00:00.000Z",
    "github_url": "https://github.com/Johnoris/hng-task-0"
}
```
